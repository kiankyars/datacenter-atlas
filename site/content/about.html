What this is

{{site_name}} maps data-centre construction that can be checked. Each project in it has a dated report of physical work from an authoritative source, a reviewed locator whose precision is stated, and links to every source it rests on, with retrieval times, content hashes and licences. Unknowns stay unknown, and nothing is inferred to make a record look complete.

The data is the Verified Construction Core, maintained by Kian Kyars. Browse it on the map, as a list of sites or by country; download it in several formats from the data page; or query the static JSON API. The methodology explains what qualifies and what the data does not claim.

How to cite

Cite the dataset version you used; its pinned downloads never change.

Kyars, K. ({{dataset.checkpoint_year}}). Data Center Atlas: Verified Construction Core (Version {{dataset.id}}) [Data set]. {{base_url}}

@misc{kyars{{dataset.checkpoint_year}}datacenteratlas,
  author = "Kyars, Kian",
  title  = "Data Center Atlas: Verified Construction Core",
  year   = "{{dataset.checkpoint_year}}",
  note   = "Dataset version {{dataset.id}}, checkpoint {{dataset.checkpoint_date}}",
  url    = "{{base_url}}"
}

The repository's CITATION.cff carries the same metadata for reference managers and GitHub's "Cite this repository" button.

Corrections and suggestions

Found an error, or know of a construction project that qualifies? Use the correction form or the new-site form on GitHub. Every site page also has a "Report a correction" link that fills in the site ID. Please link public, primary sources, with dates.

Published versions are frozen: an accepted correction is applied, and documented, in a later checkpoint. Suggestions are reviewed against the selection rules and are never added automatically.

Privacy

This site sets no cookies and uses no analytics, advertising or tracking, and it loads no scripts or fonts from other sites. When a map is shown, your browser requests basemap tiles directly from CARTO, OpenStreetMap or EOX, which receive your IP address and the map area requested. The map remembers settings such as your basemap choice in your browser's local storage; they are not sent anywhere. The site is hosted on GitHub Pages, which logs visitors' IP addresses for security purposes (GitHub's data-collection note). The OpenStreetMap, Google Maps, Bing Maps and Copernicus Browser links on site pages are only followed if you click them.

Source code and credits

The site, API and downloads are generated from the public repository kiankyars/datacenter-atlas by a standard-library Python builder, and the frontend has no build step.
